## About This Lab

In this hands-on workshop you will experience the **Microsoft Fabric** end-to-end analytics platform. Starting from a fully provisioned Fabric environment, you will build a **Lakehouse**, ingest sample data, and create a **PowerBI DirectLake** report — all without leaving the Fabric portal.

A fully isolated Fabric environment is provisioned for you — no subscription setup required.

## What You'll Learn

- Navigate Microsoft Fabric
- Create a Lakehouse
- Load data into Lakehouse Tables and Files
- Upload a local CSV file into Lakehouse Files and promote it to a Delta table
- Query data using SQL Analytics Endpoint
- Create a DirectLake semantic model over Lakehouse tables
- Build and publish a PowerBI report using DirectLake mode
